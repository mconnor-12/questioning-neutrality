💡 Why This Matters

The theory of change behind Questioning Neutrality.

Assessments are not neutral.

Every assessment reflects choices: which questions are asked, whose voices count as evidence, what kinds of thinking are rewarded. When we treat assessments as objective, we make those choices invisible — and invisible choices tend to reproduce existing inequities.

The "implied student" problem.

Every assessment imagines a student. It assumes background knowledge, cultural familiarity, language comfort, and prior experience. When that implied student doesn't match the actual students in front of us, the assessment measures cultural proximity rather than historical thinking.

Perspective is a historical skill, not a political opinion.

Including marginalized voices in assessments isn't about ideology — it's about rigor. The College Board's Historical Thinking Skills require students to consider perspective, context, and bias. A source set drawn entirely from dominant perspectives cannot generate the intellectual friction necessary for genuine historical analysis.

The Triangulation Framework.

Strong source sets include voices that stand in productive tension with each other: a government order alongside the letter of someone affected by it; a corporate regulation alongside a worker's petition. This tool operationalizes that principle by scoring your source sets on perspective diversity, gaze, and interpretive richness.

This is not about making assessments easier.

Equity and rigor are not in tension. This tool helps you design assessments that are harder in the right ways — that require genuine historical thinking, not cultural familiarity. The goal is assessments where every student can demonstrate what they actually know.

📐 Scoring Guide & Rubric

How this tool evaluates assessments, and how to export a Google Apps Script for spreadsheet integration.

Equity Scoring Dimensions

DimensionWhat it MeasuresScore Range
Perspective GazeWhose experience does this source center? (1=outsider looking in, 5=insider speaking for themselves)1–5
Neutrality ChallengeHow much does this source challenge the assumption of a "neutral" view?1–5
Interpretive RichnessHow many different valid interpretations does this source support?1–5
Access LoadHow much cultural/linguistic background knowledge does this source assume? (1=high assumption, 5=low assumption)1–5
Rigor SupportHow well does this source support AP/Regents-level historical thinking skills?1–5

Perspective Categories

CategoryDefinitionExamples
DominantVoice of those with institutional or social powerGovernment orders, court rulings, colonial records
ResistantVoice challenging or outside dominant power structuresWorker petitions, enslaved narratives, anti-imperial speeches
InstitutionalOfficial institutional voice (can be progressive or conservative)Constitutions, treaties, congressional debates
AmbiguousPerspective that cuts across simple dominant/resistant categoriesInsider critiques, complex negotiations, dual-audience texts

Google Apps Script Export

Copy this script into a Google Sheets Apps Script editor to build a spreadsheet version of this audit tool.

tag // It adds a "🔄 Sync from Sheets" button to the Library tab // Sheets Web App URL — set this once after you deploy your Apps Script // Leave as empty string to use the embedded sources let SHEETS_URL = localStorage.getItem('qn_sheets_url') || ''; async function syncFromSheets() { if (!SHEETS_URL) { const url = prompt( 'Enter your Google Apps Script Web App URL:\n' + '(Deploy → Manage deployments → copy the /exec URL)' ); if (!url) return; SHEETS_URL = url.trim(); localStorage.setItem('qn_sheets_url', SHEETS_URL); } const btn = document.getElementById('sync-btn'); if (btn) btn.textContent = '⏳ Syncing...'; try { const res = await fetch(SHEETS_URL); const data = await res.json(); if (data.error) throw new Error(data.error); // Map Sheet columns → app source schema const colMap = { 'ID': 'id', 'Title': 'title', 'Author': 'author', 'Date': 'date', 'Era': 'era', 'Type': 'type', 'Perspective': 'perspective', 'Gaze': 'gaze', 'Topic': 'topic', 'Region': 'region', 'Standards': 'standards', 'Audience Assumed': 'audienceAssumed', 'Attribution': 'attribution', 'Excerpt': 'excerpt', 'Equity Note': 'equityNote', 'Neutrality Challenge (1-5)': 'neutralityChallenge', 'Interpretive Richness (1-5)': 'interpretiveRichness', 'Access Load (1-5)': 'accessLoad', 'Rigor Support (1-5)': 'rigorSupport', }; const mapped = data.sources.map(row => { const src = {}; Object.entries(colMap).forEach(([sheetCol, appField]) => { if (row[sheetCol] !== undefined) { let val = row[sheetCol]; // Parse numeric fields if (['neutralityChallenge','interpretiveRichness', 'accessLoad','rigorSupport'].includes(appField)) { val = parseInt(val) || 0; } // Parse standards array if (appField === 'standards') { val = val ? val.split(';').map(s => s.trim()).filter(Boolean) : []; } src[appField] = val; } }); // Parse identity field if present if (row['Identity']) { src.identity = {}; row['Identity'].split(';').forEach(pair => { const [k, v] = pair.split(':').map(s => s.trim()); if (k && v) src.identity[k] = v; }); } return src; }).filter(s => s.id); // Replace the live SOURCES array SOURCES.length = 0; mapped.forEach(s => SOURCES.push(s)); if (btn) btn.textContent = `✅ ${mapped.length} sources loaded`; renderLibrary(); // Show last sync time const syncEl = document.getElementById('sync-time'); if (syncEl) syncEl.textContent = `Last sync: ${new Date().toLocaleTimeString()}`; console.log(`Synced ${mapped.length} sources from Google Sheets`); } catch(err) { console.error('Sheets sync failed:', err); if (btn) btn.textContent = '❌ Sync failed — check URL'; alert('Sync failed: ' + err.message + '\n\nCheck your Web App URL in Settings.'); } } function clearSheetsUrl() { SHEETS_URL = ''; localStorage.removeItem('qn_sheets_url'); alert('Sheets URL cleared. App will use embedded sources.'); }
